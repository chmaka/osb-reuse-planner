# Agent instructions — OSB Reuse Lab

1. Read README and docs before edits; do not claim completed future phases.
2. Keep one canonical millimeter geometry model. Never use a rendered SVG/pixel measurement as production geometry.
3. Maintain independent containment/collision validator for solver outputs.
4. Never auto-verify scans, create machine-ready DXF, generate G-code or command Mach3.
5. Preserve original photos and audit changes; report source licenses and exact limitations.
6. Keep the local PWA functional offline. Avoid mandatory cloud services or model downloads.
7. Commit tested code and disclose any unrun tests or physical checks.
