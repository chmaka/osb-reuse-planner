# Measurement protocol

1. Place the entire offcut on a contrasting, evenly lit plane; ideally use a fixed overhead station.
2. Reference marks must be in the same geometric plane as the OSB top surface or a validated height compensation must be applied.
3. For the temporary two-point method, select two clear reference points and enter their measured distance in mm. This corrects scale only; it **cannot** rectify oblique perspective or lens distortion.
4. Draw every outer boundary vertex, check outline, area and displayed bounding dimensions.
5. Independently compare a known physical dimension on the object. Any mismatch or unreviewed corner blocks VERIFIED status.
6. Pilot target: ±3 mm for features up to 600 mm in a controlled station; provisional, not achieved or guaranteed.
7. Phase 0 stores only MEASURED. Never infer CNC tolerance from a phone photo alone.
